# Код-ревью Antigravity Unlocker

Дата ревью: 24 сентября 2026 года.
Окружение: **Python 3.11.15** (macOS 14+, Apple Silicon / Intel).

## Критические замечания — исправлены

1. **Локальный API принимал запросы от посторонней веб-страницы.** Wildcard CORS и
   отсутствие подтверждения сессии позволяли странице в браузере инициировать
   изменение файлов, откат или перезапуск. Добавлены случайный session token,
   проверки `Host`, `Origin`, `Content-Type`, размера тела и allowlist операций.
   Публичная выдача токена через `/api/session` удалена: приложение передаёт
   секрет во fragment URL, а все читающие и изменяющие API требуют заголовок.
2. **Параметр перезапуска допускал внедрение команды в AppleScript.** Произвольное
   имя больше не принимается: интерфейс передаёт ID, который сервер сопоставляет
   с известным приложением; команды выполняются без строковой интерполяции.
3. **Интерфейс мог сообщать об успехе после частичной или полной ошибки.** Результат
   теперь формируется из реальных итогов binary/JS операций, а proxy и главный
   переключатель не включаются при ошибке или отсутствии выбранных целей.
4. **Состояние гонки (Race condition) в `_status_data()`.** Метод `stats.copy()`
   выполнял мелкое копирование, из-за чего список `recent_requests` мутировал во
   время сериализации `json.dumps()` при фоновом трафике, вызывая
   `RuntimeError: list changed size during iteration`. Добавлено глубокое
   копирование под блокировкой.
5. **Аварийное завершение бэкенда в fallback-режиме `desktop_app.py`.** При
   недоступности `pywebview` скрипт открывал страницу в браузере и сразу завершал
   процесс, убивая daemon-поток сервера. Добавлен цикл удержания процесса до Ctrl+C.

## Высокий приоритет — исправлено

1. **Конфигурация записывалась неатомарно и с правами по умолчанию.** Реализованы
   временный файл, `fsync`, атомарная замена, приватные права `0700/0600` и
   потокобезопасная блокировка `CONFIG_LOCK`.
2. **Шторм перезапусков и DoS на Language Server в `watchdog_worker()`.** При
   невозможности пропатчить приложение воркер бесконечно перезапускал LSP каждые
   10 секунд. Реализован экспоненциальный cooldown и лимит попыток.
3. **Утечки файловых дескрипторов (сокетов) в `proxy.py`.** Добавлено гарантированное
   закрытие сокетов в `except`-блоках при сбоях соединений к `SMART_RESOLVERS`,
   SOCKS5 и HTTP upstream.
4. **Широкий `pkill -f language_server`.** Вызов заменен на поиск конкретных PID,
   запущенных внутри бандла целевого приложения, и точные имена бинарников (`-x`).
5. **Зависшая переменная окружения после удаления службы.** В `uninstall_service.sh`
   добавлен вызов `launchctl unsetenv AG_LS_PROXY`.
6. **Идемпотентность патча бинарников.** Повторный вызов `patch_binary_file` больше
   не перезаписывает файл и не перезапускает сервер, а возвращает `(True, "Уже пропатчен")`.
7. **CONNECT-прокси мог обращаться к любому локальному адресу.** Разрешены только
   публичные назначения TLS на порту 443; loopback, private, link-local и
   special-use адреса блокируются, а direct-соединение использует уже проверенный
   результат DNS.
8. **Изменение JS нарушало подпись приложения.** После binary/JS патча теперь
   переподписывается и проверяется bundle; при ошибке восстанавливается backup.
9. **Частичное применение настроек.** Payload полностью валидируется на копии,
   затем атомарно сохраняется и публикуется под блокировкой.
10. **LaunchAgent использовал предсказуемые журналы в `/tmp`.** Plist создаётся
    через `plistlib`, проверяется `plutil`, журналы хранятся с приватными правами
    в `~/.agunlocker_mac`.
11. **Резервная копия не имела проверки целостности.** Для новых backup-файлов
    создаётся SHA-256 manifest; при несовпадении откат прекращается. Старые
    резервные копии поддерживаются с явным предупреждением в журнале.

## Средний приоритет — исправлено

1. **Обновление кодовой базы на Python 3.11.** Все модули переписаны с нативной
   типизацией Python 3.11 (`|`, `dict[str, Any]`, `list[str]`), настроен `.venv` и
   `pytest.ini`.
2. **Поддержка IPv6 в CONNECT.** Адреса вида `[::1]:8443` теперь парсятся корректно.
3. **Динамический список приложений в UI.** Селектор программ теперь отображает
   все обнаруженные приложения (включая CLI и пользовательские пути).
4. **Снижение нагрузки на CPU и батарею.** Добавлен адаптивный polling: при
   сворачивании окна интервал опроса переключается с 3.5 до 10 секунд.
5. **Ограничение кэша детектора.** Предотвращена утечка памяти в
   `_BINARY_STATUS_CACHE` с автоочисткой при модификации файлов.

## Ревью от 25 сентября 2026 года — Реализовано

1. **Встроенный обход DPI (механика ByeDPI / фрагментация TLS):**
   - В `proxy.py` добавлен алгоритм сегментации TLS ClientHello (`split 2` с микрозадержкой 3 мс и флагом `TCP_NODELAY`). Имя блокируемого домена разрывается между двумя TCP-пакетами, что предотвращает обнаружение SNI со стороны ТСПУ/DPI провайдера.
   - В UI (`index.html`, `app.js`), API (`server.py`) и конфигурацию (`config.py`) добавлен режим `tls_split` («🛡️ Обход DPI (Фрагментация TLS)»).
2. **Бесперебойный доступ к Google Gemini и Cloud Code без VPN:**
   - В `CLOUDCODE_HOSTS` и `is_google_service` в `proxy.py` добавлены `generativelanguage.googleapis.com`, `oauth2.googleapis.com`, `accounts.google.com`, `antigravity.google`, `antigravity-unleash.goog`, а также зоны `.goog`, `.gstatic.com`, `.googleusercontent.com`.
3. **Исправление несовпадения имен кандидатов при перезапуске:**
   - В `patcher.py` расширен поиск кандидатов по ID и альтернативным именам (`Antigravity`, `Antigravity 2.0 (Desktop)`).
   - В `detector.py` детекция запущенного процесса дополнена проверкой `bundle_base` (`Antigravity`).
4. **Очистка репозитория и автоочистка сборок:**
   - Удалено более 3.1 ГБ временных файлов и кэшей из папки `build/`, удалены системные `.DS_Store`.
   - В `scripts/build_macos.py` добавлен блок `try...finally` для автоматической очистки временной директории `build_root` и флаг `--keep-build`.
5. **Тестирование и валидация:**
   - Добавлены модульные тесты для проверки фрагментации пакетов и сохранения настроек в `tests/test_core.py`.
   - Тестовый набор расширен до 43 тестов (все 43 пройдены успешно).
