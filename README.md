# Antigravity Unlocker — by Kadmeia

> **Важно:** это неофициальный macOS-форк и производная работа
> [Open AG Patcher](https://github.com/AvenCores/open-antigravity-patcher).
> Оригинальный проект и основная идея принадлежат
> [AvenCores](https://github.com/AvenCores).

Графическое локальное приложение для управления macOS-адаптацией Open AG
Patcher. Интерфейс показывает найденные установки Antigravity, применяет
поддерживаемые локальные изменения, управляет локальным CONNECT-прокси и умеет
восстанавливать оригинальные файлы из резервных копий.

## Скачать

В папке `release/` создаются отдельные приложения:

- `Antigravity Unlocker-arm64.app` — Apple Silicon (M1/M2/M3/M4 и новее);
- `Antigravity Unlocker-x86_64.app` — Intel Mac;
- соответствующие DMG, полноценные установщики `.pkg` и `SHA256SUMS.txt`.

При первом запуске используйте Finder: правый клик по приложению →
«Открыть». Не отключайте Gatekeeper глобально.

Проверенный минимум текущего сборочного окружения — macOS 14. Intel-сборка
создаётся как настоящий x86_64 bundle и проверяется под Rosetta; окончательная
приёмка на физическом Intel Mac всё равно рекомендуется.

## Возможности

- обнаружение Antigravity IDE, Desktop и CLI в стандартных путях;
- резервная копия перед изменением и безопасный отказ от эвристического отката,
  если точной копии нет;
- проверка результата кодовой подписи;
- локальный прокси на `127.0.0.1` с direct, smart и custom upstream режимами;
- CONNECT разрешён только к публичным TLS-адресам на порту 443; локальные и
  частные сети блокируются;
- защищённый localhost API с токеном, передаваемым приложением через URL fragment,
  проверкой Origin/Host и
  строгой валидацией запросов;
- диагностика, журнал событий и отчёт для поддержки;
- отдельные автономные сборки Apple Silicon и Intel.

## Ограничения

- Патчи зависят от конкретных сигнатур версий Antigravity. Неизвестная версия
  должна завершаться ошибкой, а не сообщением об успехе.
- В текущей реализации машинный ARM64 gate применяется только к ARM64-бинарнику;
  Intel-сборка интерфейса не означает наличие отдельного x86_64 machine-code
  gate. Строковые патчи применяются только при точном совпадении сигнатур.
- Диагностический HTTPS-запрос подтверждает сетевую достижимость, но не выдаёт
  лицензию и не гарантирует доступность аккаунта или сервиса.
- Применение может нарушать условия стороннего сервиса. Пользователь сам отвечает
  за соблюдение применимых правил и законодательства.

## Запуск при скачивании с GitHub

Приложение готово к запуску «из коробки» без ручной настройки:

### Вариант 1: В 1 клик через Finder (рекомендуется)
Сделайте **двойной клик** по файлу **`launch.command`** в папке проекта.  
При первом запуске скрипт автоматически обнаружит лучший интерпретатор Python (3.11+), создаст изолированное окружение (`.venv`), установит необходимые компоненты (`pywebview`) и сразу откроет нативное окно приложения.

### Вариант 2: Через Терминал
```bash
./start.sh
```
Скрипт выполнит автоматическую проверку и настройку окружения и запустит программу.

*(Опционально) Ручной запуск:*
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python desktop_app.py
```

## Сборка приложений

Сборка выполняется нативным Python соответствующей архитектуры:

```bash
python3 -m pip install -r requirements-build.txt
python3 scripts/build_macos.py --arch arm64

arch -x86_64 /path/to/x86_64/python scripts/build_macos.py --arch x86_64
```

Скрипт создаёт thin bundle, проверяет архитектуру каждого Mach-O файла,
применяет ad-hoc подпись, проверяет `codesign`, создаёт DMG и полноценный PKG с
лицензионным экраном и установкой в `/Applications`. DMG проверяется через
`hdiutil verify`. В сборки включаются GPL, дополнительное пользовательское
соглашение, уведомления о компонентах и соответствующий исходный код сборки.

## Безопасный откат и удаление

Используйте «Настройки → Вернуть оригинал». Откат выполняется только из точной
резервной копии. После закрытия локальной службы прежнее значение
`AG_LS_PROXY` восстанавливается; значение, изменённое другим процессом, не
перезаписывается.

Настройки находятся в `~/.agunlocker_mac`. Удаляйте этот каталог только если вам
не нужны конфигурация и журнал приложения.
