## Описание релиза

Antigravity Unlocker by Kadmeia — автономное macOS-приложение с локальным WebKit
интерфейсом. В релиз входят отдельные thin-сборки для Apple Silicon (`arm64`) и
Intel (`x86_64`), DMG-образы и SHA-256 контрольные суммы.

Первый запуск: правый клик по приложению в Finder → «Открыть». Intel-вариант
проверен как x86_64 под Rosetta; для окончательной приёмки рекомендуется тест на
физическом Intel Mac.
